# Task specification

Connecting devices

User needs to develop hardware specific code that runs on Raspberry Pi with the help of codemowers/agent

SSH access would be possible but not preferred. Raspberry Pi can reach codemowers/agent web endpoint.

## Confirmed scope (from issue discussion)

- Three device commands: `shell`, `file_read`, `file_write`
- No MCP proxying — device tools injected into existing Agent MCP when device toggled into task
- Go binaries published as GitHub releases (linux/amd64, arm64, armv7)
- Separate repo: https://github.com/codemowers/device-agent
- Vanilla Linux only for now (no ESP32)
- UI: connected devices appear in navbar; user toggles to include in current task

## Connection model

Device runs `device-agent --endpoint wss://host/devices/KEY`. Key is generated in
controller UI and shown as a copy-pastable URL. Device sends hostname on connect;
controller tracks presence in Redis. Any connected device appears in navbar.
